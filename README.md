# FrameFlow — محوّل الفريمات والسلاسة

نسخة عربية محدثة من مشروع Android لتحويل الفيديو إلى 60 أو 120 FPS باستخدام **استيفاء فريمات بالحركة** عبر FFmpeg `minterpolate`.

## المميزات
- واجهة عربية بالكامل.
- اختيار فيديو من الجهاز.
- 60 FPS أو 120 FPS.
- 3 مستويات للسلاسة: عادي / قوي / أقصى.
- اختيار الدقة: الأصلية / 1080p / 720p.
- الحفاظ على الصوت AAC.
- استخدام H.264 عبر MediaCodec عند توفره.
- حفظ النتيجة تلقائيًا داخل Movies/FrameFlow.
- شريط تقدم وحالة التحويل.
- مناسب لأجهزة Android 64-bit الحديثة مثل POCO X7 Pro.

## البناء
افتح المجلد في Android Studio مع اتصال بالإنترنت ثم شغّل `assembleDebug`.

> ملاحظة: التطبيق يولّد فريمات وسيطة فعلية بواسطة motion-compensated interpolation. الوصول إلى سلاسة ممتازة يعتمد على حركة الفيديو، الإضاءة، الدقة، وقدرات الجهاز؛ لا يمكن ضمان أن كل فيديو سيبدو مثاليًا.

محرك FFmpeg يتم تنزيله عند أول تشغيل من مشروع Android-FFmpeg-Prebuilt المشار إليه في الكود.
